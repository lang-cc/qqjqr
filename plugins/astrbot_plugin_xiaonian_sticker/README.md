# 小年表情包口袋

别人发的表情包**先只进候选池**，大肥鱼看着顺眼才收进库；限额 **200 张**，满了用 `/表情清理` 腾地方。

## 流程

```
群友发表情包
   ↓  （不用 @ 机器人、不用唤醒词）
候选池（内存里，默认留 60 条，重启清空）
   ↓  /收列表 看清单 → 引用那张图发 /收（或 /收 编号 / /收 链接）
表情包库（data\sticker_pocket\，上限 200 张，去重）
   ↓  /表情 随机发出去
```

想改成来者不拒：面板里把 `auto_collect` 打开即可（默认关）。

## 指令

| 指令 | 作用 | 谁能用 |
|---|---|---|
| `/收` | 引用那张表情包发，收进库（不带引用时收本会话最近一张还没收的） | 大肥鱼 / 管理员 |
| `/收 3` | 收候选池里编号 3 的那条（编号从 `/收列表` 看） | 大肥鱼 / 管理员 |
| `/收 http://…` | 直接收一个图片链接 | 大肥鱼 / 管理员 |
| `/收列表` | 这个会话最近看到哪些图，收了没 | 所有人 |
| `/表情` `/表情 3` | 随机发 1 张 / 连发 3 张（≤ `send_limit`） | 所有人 |
| `/表情库` | x/200、多少 MB、各群收了多少、最常用、候选池还剩几条 | 所有人 |
| `/表情列表 15` | 最近收的，带编号、用了多少次 | 所有人 |
| `/表情清理 20` | 按「用得最少 + 最久没发」删 20 张 | 大肥鱼 / 管理员 |
| `/表情删 12 15` | 按编号删 | 大肥鱼 / 管理员 |
| `/表情诊断` | 收不到图时看处理流水（原始消息段长什么样、为什么没进池） | 所有人 |
| `/表情帮助` | 上面这些 | 所有人 |

「大肥鱼」= `owner_ids` 里的 QQ 号，默认 `3862642627`（群名片「群主的大肥鱼——鱼」），面板里可改；面板管理员 `admins_id` 始终放行。

## 存在哪

```
data\sticker_pocket\
  index.json                             每张的 id / sha1 / 来源 / 使用次数 / 最后使用时间
  group_<群号>\0001_<发送人QQ>.png    ← 该群里收的
  private_123456\0002_123456.gif         ← 私聊收的
```

- **sha1 去重**：同一张反复收也只存一份。
- 放 `data\` 而不是插件目录，重装/更新插件不会把库弄丢。

## 怎么拿到原始图片（技术说明）

- 不用 `@filter.event_message_type(ALL)`：AstrBot 的 `waking_check` 阶段会把未唤醒消息
  `stop_event()`，普通 handler 根本跑不到；而且 `mface`（QQ 商城/收藏表情）在
  aiocqhttp 适配器里是被 `continue` 直接丢掉的。
- 这里直接订阅原始 OneBot 事件总线 `bot.subscribe("message", handler)`：
  未唤醒也收得到，`mface` 的 `url` 也还在，两个坑都绕开。
- 平台实例可能比插件晚加载，所以有 10 秒一次的巡检自动挂载。

## 配置（面板 → 插件 → 本插件）

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 关掉后连候选池都不进 |
| `auto_collect` | **false** | 关：只进候选池等 `/收`；开：来者不拒自动全收 |
| `recent_keep` | 60 | 候选池保留条数（内存） |
| `owner_ids` | `["3862642627"]` | 谁有资格挑/删 |
| `max_count` | 200 | 总上限；装满后新图进不来，日志 warning |
| `warn_at` | 180 | 到 180 张时 `/表情库` 告警、日志 warning |
| `max_file_kb` | 1024 | 单张体积上限 |
| `max_side` | 1200 | 单张最长边上限（过滤照片） |
| `text_message_ok` | false | 带文字的图片消息是否也进候选池（引用 `/收` 不受限） |
| `send_limit` | 5 | 一次最多发几张 |

想扩到 300 张：`max_count` 改 300、`warn_at` 改 270，不用改代码。

## 注意

- 只处理机器人自己在的群/好友发来的消息，不碰别人的私有数据。
- 表情包都是别人发的图，自己留着发着玩可以，别拿去商用或当成自己的原创作品。
