# 记忆大脑 + 真人感 + 上下文压缩（整合版）

一个插件同时管三件事：**记得住**（长期记忆）、**说得像人**（风格护栏）、**不撑爆上下文**（按重要性压缩历史）。

数据全部只进本地 SQLite：`data/plugin_data/astrbot_plugin_xiaonian_memory/brain.db`，不外传。

---

## 一、它解决什么问题

原来的问题是上下文被**人设副本**撑胖了：humanlike 把整段 system_prompt 搬进每条 user 消息，历史里 87% 都是重复的设定文本。

实测（2026-10-29，本机真实会话）：

| 项 | 改造前 | 改造后 |
|---|---|---|
| 6 个会话历史总 token | 150,335 | **9,563**（降 93.6%） |
| 群 `<群号>` | 98,268 | **5,152** |
| 每轮请求（含注入块） | 10 万级 | **约 7,000** |
| 记忆条数 | 0 | **99**（历史导入 93 + 新沉淀） |

## 二、命令

| 命令 | 作用 | 谁能用 |
|---|---|---|
| `/账本` | 看上一轮 prompt 的开销构成（历史/system/prompt 各多少字、多少 token） | 所有人 |
| `/压缩预览` | 只算不改：压完会留哪些轮、摘要长什么样、会写哪些事实进记忆 | 所有人 |
| `/压缩` | 立刻压缩一次（dry_run 开着就只预览） | 主人 |
| `/人格候选` | 看攒够次数的说话习惯（≥3 次、跨 ≥2 天） | 所有人 |
| `/人格补丁` | 生成人格追加补丁的**预览**，不写入 | 所有人 |
| `/人格应用 确认` | 真正追加进人格（先自动备份） | 主人 |
| `/人格回滚` | 退回上一次人格备份 | 主人 |
| `/人格diff` | 看人格改动记录 | 所有人 |
| `/大脑` | 记忆库状态与检索测试 | 所有人 |

## 三、压缩是怎么压的

不是按时间硬切，是**四路分流**：

1. **最近 N 轮原文**（私聊 20 / 群聊 12）—— 保证接得上话；
2. **重要原话**（私聊 20 / 群聊 12 轮，跨时间挑）—— 承诺、约定、任务、情绪事件、生活事件；
3. **摘要** —— 其余部分压成「前情提要」，要求数字/日期/人名**逐字保留**；
4. **事实 → 记忆库** —— 长期沉淀，跨会话可用。

硬保护：
- 被压掉的原文全部留档在 `data/plugin_data/…/pruned/`，可翻可恢复；
- 单条消息超 8,000 字自动截断（防有人贴整篇文档）；
- 摘要预算上限 8,000 token（再长就不叫压缩了）。

触发阈值（实测网关支持 12 万 token，所以 5 万压线很安全）：

| 阈值 | 触发后 |
|---|---|
| **5 万 token**（压线） | 压到 1/2 |
| **7.5 万 token**（硬保险） | 压到 1/3 |

## 四、人格演进怎么变

- **硬层永不动**：身份、关系、硬性规则 —— 代码里根本不碰，只在软层尾部追加；
- **软层追加**：标记 `【随日子长出来的习惯】` 之后的内容才会长；
- **门槛**：同一条观察出现 ≥3 次且跨 ≥2 天，才进候选；
- **默认不自动写**：`evolve_auto=false`，只攒候选，等 `/人格补丁` 看过再 `/人格应用 确认`；
- **可回头**：每次改动前备份 + 写 `persona_changelog.md`，`/人格回滚` 撤回。

## 五、上线默认状态（安全优先）

| 开关 | 默认 | 含义 |
|---|---|---|
| `compress_enabled` | 开 | 触发检查照跑 |
| `compress_dry_run` | **开** | 只统计不落地，观察几天再关 |
| `strip_inject_on_save` | 开 | 请求前把注入块剥掉（降 token 的关键） |
| `ledger` | 开 | 每轮打开销账本 |
| `evolve_auto` | **关** | 人格只观察，不自动改 |

**建议节奏**：先跑 3~5 天看 `/账本` 和 `/压缩预览`，确认摘要质量没问题，再把 `compress_dry_run` 关掉让压缩真正落地。

## 七、回滚

| 要撤销什么 | 怎么做 |
|---|---|
| 压缩结果 | 用 `pruned/` 里的原文手动还原，或直接用 `data_v4.db.before_clean_*` 备份 |
| 人格改动 | `/人格回滚` |
| 整个插件 | 停服 → 删 `data/plugins/astrbot_plugin_xiaonian_memory` → 用 `backups/data_v4.db.*` 恢复历史 |
| 配置瘦身（max_turns/ICL/技能） | `backups/cmd_config.json.*`、`backups/skills.json.*` |

## 八、已知边界

- **没有 embedding 提供方**：检索走 SQLite FTS5 关键词，召回不如向量但零依赖；配了 embedding 会自动升级。
- **多模态默认关**：图片/语音/视频记忆需要 `pilk` / `faster_whisper` / ffmpeg，没装就不启用。
- **群聊 ICL**：已从 1000 条降到 200 条，需要更长的群上下文可用工具按需查。
